
function ifExistTriangle(adjacency_matrix,n){
    for(int i=0; i<n; i++){
        for(int j=0; j<n; j++){
            for(int k=0; k<n; k++){
                if(adjacency_matrix[i][j]==1 &&
                adjacency_matrix[i][k]==1 &&
                adjacency_matrix[j][k]==1 ){
                    return True;
                }
                
            }
        }
    }
    return False;
}


Runtime analysis:
Time conplexity O(n^3): Because there are 3 loops nested together. The inner loop runs for n times per one index change in the middle loop. The middle loop will run n*n times per one index change in the outer loop. The outer runs n times. Therefore, in total, the algorithm will run the if statement for n^3 times.
